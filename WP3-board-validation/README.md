# WP3 · Board validation

Notes on the contents of this folder. The tasks and their estimated duration are in [ROADMAP.md](../ROADMAP.md).

## Objective

To check on hardware that the tests chosen in simulation hold: simple boards with typical analog blocks (Sallen-Key, biquad and similar) and fault injection, measured with the ADC and DAC of a microcontroller that runs the exported self-test plan. The boards are kept deliberately simple: the aim is to validate the method, not an application. It ends at milestone G3: the simulated test ranking holds on the board.

## Status

Not started. Requires the self-test plan of WP2; board design can start while the WP2 experiments are being closed.
