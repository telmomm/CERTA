# WP4 · Applications

Notes on the contents of this folder. The tasks and their estimated duration are in [ROADMAP.md](../ROADMAP.md).

## Objective

To show that the method, which is domain-neutral, yields a usable self-test plan in real applications where the risk is of a different kind in each one. For each case: circuit model, fault table with severities, self-test plan and risk-weighted coverage.

| Case | Kind of risk |
| --- | --- |
| Cell voltage and current measurement chain of a battery management system | Functional safety |
| ECG front end | Patient safety (IEC 60601, ISO 14971) |
| Bridge sensor conditioning (strain gauge or thermistor) in an unattended measurement node | Data integrity |

The specific circuits are still to be refined.

Not started. Requires milestone G2 (WP2) and the case sheets defined in WP1.
