# WP4 · Biomedical application

Notes on the contents of this folder. The tasks and their estimated duration are in [ROADMAP.md](../ROADMAP.md).

## Objective

To apply the method to biomedical front ends, where faults have an impact on patient safety: ECG front end and Howland current source with severities according to IEC 60601, a generic industrial case, the self-test plan exportable from the web GUI and the open dataset.

## Status

Not started. Requires milestone G2 (WP2); the data part requires the WP3 measurements.
