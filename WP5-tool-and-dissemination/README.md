# WP5 · Tool and dissemination

Notes on the contents of this folder. The tasks and their estimated duration are in [ROADMAP.md](../ROADMAP.md).

To make the result usable by others: the self-test plan exportable from the web GUI starting from a netlist, documentation with a worked example from netlist to firmware, the open dataset of simulations and measurements, and teaching material.

Not started. Requires milestone G2 (WP2); the dataset requires the WP3 measurements. It runs in parallel with WP4.
